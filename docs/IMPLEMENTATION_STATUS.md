## 明确未做（第一版范围外）

- BLE 开盒弹窗：需要先实测 X4 的广播帧（见 [PROTOCOL_FINDINGS.md](PROTOCOL_FINDINGS.md) §6）。
- OTA 固件刷写。
- 欢律中依赖手机的功能：听力增强测试、耳机专注、对话感知（官方说明连接电脑时不生效）、AI 摘要、翻译等。

## 性能（实测）

- 发布版自包含 win-x64：安装包约 48 MB，安装后约 178 MB / 479 文件，含 `EncoDeck.pri` 等关键文件。
- 托盘常驻空闲：实测 60 秒窗口 CPU ≈ 0.18% / 单核，工作集约 128 MB、私有约 73 MB。
- `--background` 启动 → 发现 X4 → `--exit` 干净退出（退出码 0）。
